# AUDITORIA-DE-COHERENCIA-FINANCIERA

Sistema independiente para detectar inconsistencias, correlaciones y tendencias en estados financieros.

## V0.6
- Identificación del cliente.
- Carga de Balance, Resultados y Flujo.
- Lectura de XLSX/XLS/CSV.
- Control previo de lectura: archivo, hoja, períodos y cuentas reconocidas.
- Preparado para normalización y motor de pruebas.

## Principio
Una alerta es un indicio analítico, no una acusación de error, irregularidad o fraude. Cada hallazgo deberá mostrar números, fórmula, base del cálculo, razón de la alerta e interpretación.
